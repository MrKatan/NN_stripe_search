## Пример набора данных 

Данный набор соответсвует одному экперименту, в котором моделировалось изменение магнитных моментов некоторого образца при изменении температуры.
Каждое изображение соответствует конфигурации магнитных моментов при определенной температуре
При различных условиях экперимент мог закончится с образованием полосовых доменов

# NN_stripe_search
Нейросеть, способная предсказывать появление доменных структур («страйпов») по изображению, представляющие из себя конфигурацию магнитных моментов при определенных параметрах

## 🎯Постановка задачи 
В ходе работы обучалась нейросеть, способная по изображениям конфигурации магнитных моментов при определенной температуры предсказывать появление стабильных структур - `страйпов` (от англ. stripe - "полоса") при текущей скорости изменения температуры.

## 🗃️ Обучающий набор данных 

Пример набора данных находится в папке **`/Resources/Dataset_example/`** 

В этой папке представлены набор изображений, соответсвущий одному эксперименту. Каждое изображение соответствует *`конфигурации магнитных моментов системы при определенной температуры`*. При работе изпользовались результаты множества таких экспериментов. Каждый экперимент отличался скоростью изменения температуры системы и мог приводит к образованию страйпов.  

Для предсказания появления страйпов нейросеть анализировала три изображения (состояние системы при "текущей" температуре и предыдущие состояния). Такой триплет, в зависимости от образования через некоторое время страйпов, помечался как `0`, если страп не образуется, и `1`, если образуется страйп

При обучении изпользовался датасет, состоящих из 1600 элементов, который был разделен на тренировочный (1280 элементов) и тестовый (320 элементов) набор.

## ✅ Результат 

В ходе работы удалось обучить нейросеть предсказывать появление полосового домена через два шага по температуре. Для оценки качества моделей использовалась метрика «accuracy», которая составила `0.8`. 
Попытка увеличить количество шагов, за которое можно предсказать образование страйпов приводить к тому, что нейросеть не обучается совсем
